# e-Bhoomi — Phase 1B: Real Telugu OCR Integration

## Overview
Phase 1B integrates the first **REAL OCR engine** into **e-Bhoomi** (SIH26018 — Intelligent Land Record Digitization & Validation), extending the Phase 1A OpenCV document pre-processing foundation. The pipeline accepts preprocessed page images generated by OpenCV, segments text lines, runs server-side inference through `TeluguOCRProvider`, and returns normalized page-wise OCR text ready for downstream translation and NLP processing.

---

## 1. TeluguOCR Model Source & Strategy
- **Repository**: [harsha-desaraju/TeluguOCR](https://github.com/harsha-desaraju/TeluguOCR)
- **Model Candidate**: [harsha-desaraju/telugu-ocr-model](https://huggingface.co/harsha-desaraju/telugu-ocr-model)
- **Engine Type**: Line-level VisionEncoderDecoder / TrOCR neural architecture.

---

## 2. Pluggable OCR Provider Architecture (`BaseOCRProvider`)
To ensure the core application is not rigidly coupled to a single model, OCR processing is governed by an abstract provider interface:

```
                  BaseOCRProvider (Abstract Interface)
                                  │
          ┌───────────────────────┴───────────────────────┐
          ▼                                               ▼
  TeluguOCRProvider                             FutureEnglishOCRProvider
  (harsha-desaraju/telugu-ocr-model)            (Tesseract / PaddleOCR)
```

### Key Provider Operations
- `process_page_image(image_bgr, page_number)`
- `process_document_images(pages_bgr)`
- `get_provider_metadata()`

---

## 3. Server-Side Execution Pipeline & Line Segmentation
Because `harsha-desaraju/telugu-ocr-model` operates on line-level text crops:

```
Original Document
       ↓
Phase 1A OpenCV Preprocessed Page
       ↓
LineSegmenter (OpenCV Morphological Line Extraction & Bounding Boxes)
       ↓
TeluguOCRProvider Line Inference (PyTorch / TrOCR)
       ↓
Raw OCR Text + TeluguNormalizer (NFKC, Whitespace & Linebreak Cleanup)
       ↓
Normalized Page-Wise OCR Result JSON
```

---

## 4. Hardware Auto-Detection & Device Policy
- **CPU / GPU Detection**: Auto-detects CUDA via `torch.cuda.is_available()`.
- **CPU Execution**: Automatically falls back to CPU if no GPU hardware is detected.
- **Memory Footprint**: Controls batch inference and line token limits (`max_new_tokens=64`).

---

## 5. Truthful State Management & Error Handling
If model weights or PyTorch/transformers dependencies are missing:
- **No Fake Text**: The system NEVER generates mock or sample OCR text.
- **Truthful Status**: Returns `status: "OCR_MODEL_NOT_AVAILABLE"` with clear diagnostic guidance.
- **Retry Path**: VROs can retry OCR execution without re-uploading original or preprocessed document scans.
- **Partial Multi-Page Failure**: Tracks individual page statuses (`COMPLETED`, `OCR_FAILED`). If Page 1 succeeds and Page 2 fails, the overall status reflects `PARTIAL_FAILURE`.

---

## 6. Raw vs. Normalized Text Storage
- **`rawOCRText`**: Preserves unmodified text output directly from neural inference for debugging and audit.
- **`normalizedOCRText`**: Stores text cleaned by `TeluguNormalizer` (Unicode NFKC, whitespace/linebreak normalization, preserving Telugu characters, numbers, and punctuation).

## 8. Benchmark Harness (`scripts/benchmark_ocr.py`)
Developer benchmark tool for evaluating OCR accuracy and throughput:
```bash
python scripts/benchmark_ocr.py --file test-docs/telugu_sample.jpg
```
Measures:
- Preprocessing time vs OCR inference time
- Character Error Rate (CER) via Levenshtein edit distance
- Memory and line crop counts

---

## 9. Limitations & Next Integration Point (Phase 1C)
- **Handwriting**: Printed Telugu text is supported. Pages with detected handwriting carry `handwritingDetected: true` metadata for downstream handwriting models.
- **Semantic Field Extraction**: Phase 1B does NOT extract structured land fields (`ownerName`, `surveyNumber`). Structured extraction occurs in a downstream AI phase.
- **Translation**: Text remains in normalized Telugu (`te`). IndicTrans2 translation will consume this text in the upcoming Phase 1C.
